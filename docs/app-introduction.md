# Sticky note（便签）— 应用介绍

当前版本：**2.6.3**（最新版本以 [Releases](https://github.com/yangzhenwei777/fnos-stickynote/releases) 为准）

## 概述

Sticky note 是一款轻量、精美的多用户富文本笔记应用，面向飞牛 NAS（fnOS）家庭与团队场景。基于 Go + Vue 3 构建，单二进制部署，资源占用低。支持富文本编辑、全文搜索、笔记加密、文件夹访问锁、版本历史、分享链接、WebDAV 备份与多用户数据隔离，同时提供 Windows 离线客户端。

## 功能特性

### 写作与阅读

- **富文本编辑**：基于 Tiptap 的所见即所得体验，25 项排版能力，覆盖标题、加粗、斜体、下划线、删除线、引用、代码块、列表、任务清单、文字/背景色、字体字号、格式刷、对齐、缩进、图片、表格、链接与分割线。
- **斜杠命令**：段首输入 `/` 唤起插入菜单，支持标题、列表、任务清单、引用、代码块、表格与分割线。
- **自动保存**：停止输入 3 秒自动保存，也可 `Ctrl+S`；阅读态与编辑态分离。
- **阅读大纲**：从 h1–h3 提取目录，点击跳转；2.6.3 起标题栏固定，正文/大纲独立滚动，滚轮按指针分流，大纲滚动条停止 3 秒后隐藏。
- **导入导出**：Markdown / HTML 导入自动转富文本；单篇导出 Markdown、批量导出 ZIP、笔记导出为长图 PNG。

### 整理与检索

- **全文搜索**：SQLite FTS5 中文全文索引，短词自动回退 LIKE；支持 `tag:` / `folder:` / `sort:` / `since:` / `until:` 搜索语法。
- **文件夹**：创建、重命名、删除、拖拽排序；支持移动到、复制到其他文件夹。
- **文件夹访问锁**：设置密码后，文件夹内笔记从列表、搜索、回收站、计数与导出中隐藏；输入密码后仅在本次会话内可见，退出或会话失效即回锁。这是访问锁，不是正文二次加密。
- **回收站**：软删除可恢复；永久删除级联清理附件与版本历史。
- **附件管理**：魔数校验拒绝伪装文件；staged → attached → orphan → delete_pending 状态机；删除后保留 24 小时恢复窗口。

### 版本历史与分享

- **版本历史**：每次保存前留存上一状态；后台每 10 分钟为有变更的笔记补自动快照，内容哈希去重；支持只读预览与一键恢复，恢复前先快照当前内容。
- **保留策略**：默认每篇 50 份 / 180 天 / 全库 2GB，可在【系统配置 → 全部配置】调整；份数设为 0 可停止生成新历史，已有历史保留。
- **分享链接**：生成只读公开链接，有效期 1 / 7 / 30 天（默认 7 天），可随时撤销；token 仅创建时返回一次，数据库只存 SHA-256 哈希；公开页无需登录，带 `noindex` / `no-store`。加密笔记禁止分享。

### 安全与隐私

- **笔记加密**：AES-256-GCM + PBKDF2（600,000 次迭代）+ bcrypt；每篇独立 salt/nonce；密文落库，服务端不保存明文与笔记口令。
- **两步验证**：TOTP 动态码 + 恢复码。
- **账号找回**：预设安全问题即可自助找回密码；管理员可重置密码、禁用或删除用户。
- **并发保护**：CAS 乐观锁，多设备同时编辑时旧版本保存返回 409，不静默覆盖。
- **纵深防御**：JWT 双 token + `token_version` 全局吊销；IP / 用户名 / 账号三层防爆破；双端 XSS 消毒；CSP；外链图片剥除。
- **备份安全**：WebDAV 定时备份；`.snbak` 归档全程加密、逐文件哈希、恢复前完整性自检；凭据加密存储；主密钥可导出/导入。

### 多用户与多端

- 用户注册、登录、退出；每个用户数据完全隔离；首个注册用户自动成为管理员；多管理员告警。
- 暗色模式、响应式布局、PWA 可安装、仪表盘。
- 飞牛 App、FN Connect、浏览器统一入口；服务端 TCP + unix socket 双轨监听。
- Windows 桌面绿色版：本地 SQLite、离线可用、联网增量同步、冲突中心四种处置、DPAPI 凭据封存、便携备份 `.snbak`、WebView2 随包。

## 适用场景

- **家庭笔记共享**：成员各自记录，数据隔离、互不干扰。
- **小团队知识库**：技术文档、会议纪要、SOP 沉淀。
- **个人知识管理**：浏览器随时记录，支持加密、版本历史与全文搜索。
- **NAS 轻量笔记方案**：资源占用低、部署简单、数据自主可控。

## 技术特性

- **纯 Go 后端**：单二进制，`CGO_ENABLED=0`，无外部运行时依赖。
- **嵌入式 SQLite**：modernc.org/sqlite（纯 Go），WAL 模式，数据本地存储。
- **前端嵌入二进制**：Vue 3 构建产物内嵌，无 Node 运行时依赖。
- **数据库自动迁移**：升级自动执行，历史数据兼容。
- **JWT 双 token**：短效 access + 长效 refresh，`token_version` 支持全端吊销。
- **质量门禁**：Go 单测（含 race）、Vitest、Playwright E2E、冒烟 / 迁移 / 边界测试、真机回归、依赖漏洞差分与凭据扫描。

## 部署信息

| 项目 | 说明 |
|------|------|
| 默认端口 | 13389 |
| 数据目录 | fnOS：应用数据目录；二进制：`./data`；Docker：`/app/data` |
| 访问方式 | 浏览器打开 `http://<NAS_IP>:13389` |
| 安装包 | `StickyNote-<日期>-<版本>.fpk`（当前为 x86/amd64） |
| Docker | `davyang/sticky-note`（linux/amd64 + linux/arm64） |
| 桌面端 | Windows amd64 绿色版，解压即用 |
| 资源占用 | 低，适合 NAS 长期运行 |

> **安全提示**：生产环境建议通过 fnOS 反向代理启用 HTTPS，并设置 `COOKIE_SECURE=1`。

## 首次使用

1. 安装完成后打开应用。
2. 注册第一个账号（自动成为管理员）。
3. 在设置中开启两步验证，并为敏感笔记设置独立密码。
4. 如需自动备份，在管理后台配置 WebDAV 目标与备份计划。
5. 如需 Windows 离线使用，下载桌面绿色版并连接同一服务端。
