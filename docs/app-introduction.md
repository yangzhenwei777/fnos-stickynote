# Sticky note（便签）— 应用介绍

当前版本：**2.2.0**

## 概述

Sticky note 是一款轻量、精美的多用户笔记管理应用，面向飞牛 NAS（fnOS）家庭与团队场景。基于 Go + Vue 3 构建，单二进制部署，资源占用低，支持富文本编辑、笔记加密、两步验证、全文搜索与多用户数据隔离。

## 功能特性

### 笔记管理
- **富文本编辑**：基于 Tiptap 的所见即所得体验，支持标题、加粗、斜体、下划线、删除线、引用、代码块、有序/无序列表、文字颜色、图片、表格
- **全文搜索**：FTS5 全文索引，短词自动回退 LIKE
- **排序切换**：最近修改 / 最近创建 / 标题字母序
- **自动保存**：定时自动保存 + Ctrl+S，阅读/编辑模式分离
- **Markdown 导入导出**：单篇 + 批量 ZIP

### 安全与隐私
- **笔记加密**：AES-256-GCM + PBKDF2（600,000 次迭代）+ bcrypt，加密笔记不以明文落库
- **两步验证**：TOTP 动态码 + 恢复码
- **并发冲突保护**：CAS 乐观锁，多设备同时编辑时旧版本保存返回 409
- **附件安全**：魔数校验拒绝伪装图片的脚本文件，附件状态机管理全生命周期
- **纵深防御**：双 token + 全局吊销、防爆破三层、XSS 双端消毒、外链图片剥除、CSP

### 多用户支持
- 用户注册、登录、退出；每个用户数据完全隔离
- 首个注册用户自动成为管理员
- 安全问题找回密码；用户禁用/删除；管理员重置密码

### 界面体验
- **暗色模式**：一键切换明暗主题
- **响应式设计**：PC 与移动端适配
- **PWA**：可安装到桌面/主屏
- **仪表盘**：总笔记数与最近笔记概览

## 适用场景

- 家庭笔记共享：成员各自记录，数据隔离
- 团队知识库：小型团队技术文档、会议纪要
- 个人知识管理：浏览器随时记录
- NAS 轻量笔记方案：资源占用低、部署简单

## 技术特性

- **纯 Go 后端**：单二进制，`CGO_ENABLED=0`，无外部运行时依赖
- **嵌入式 SQLite**：modernc.org/sqlite（纯 Go），数据本地存储
- **前端嵌入二进制**：Vue 3 构建产物内嵌，无 Node 运行时依赖
- **数据库自动迁移**：升级自动执行，历史数据兼容
- **JWT 双 token**：短效 access + 长效 refresh，token_version 支持全端吊销

## 部署信息

| 项目 | 说明 |
|------|------|
| 默认端口 | 13389 |
| 数据目录 | `./data`（二进制）或 fnOS 应用数据目录 |
| 访问方式 | 浏览器打开 `http://<NAS_IP>:13389` |
| 安装包 | `StickyNote-<日期>-<版本>.fpk`（当前仅 x86/amd64） |
| 资源占用 | 低，适合 NAS 长期运行 |

> **安全提示**：生产环境建议通过 fnOS 反向代理启用 HTTPS，并设置 `COOKIE_SECURE=1`。

## 首次使用

1. 安装完成后打开应用
2. 注册第一个账号（自动成为管理员）
3. 开始创建笔记；建议在设置中开启两步验证与笔记加密
