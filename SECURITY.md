# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities. Use GitHub Security Advisories ("Report a vulnerability") on this repository so the report stays private.

Please include:

- affected version
- deployment mode (fnOS FPK, standalone binary, desktop client)
- reproduction steps
- impact assessment

We will acknowledge the report and coordinate a fix and disclosure.

## Scope

Security-relevant areas include authentication and session handling, note encryption, attachment validation, backup/restore, sync, and the desktop client's local data handling.

## Supported versions

Security fixes are provided for the latest release line.
